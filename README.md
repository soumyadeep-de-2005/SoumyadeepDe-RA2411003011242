## How to Compile and Run Each Section

Compile all sections at once:
```bash
javac -d bin $(find src -name "*.java")
```

### Run Section 1 (SRP):
```bash
java -cp bin section1.Main
```

### Run Section 2 (OCP):
```bash
java -cp bin section2.Main
```

### Run Section 3 (LSP):
```bash
java -cp bin section3.Main
```

### Run Section 4 (ISP + DIP):
```bash
java -cp bin section4.Main
```
